# Pierwsze kroki z Google Antigravity: materiały

Warsztat Tarnow Tech Community, wtorek 20.10.2026, Akademia Tarnowska.

## Jak pobrać

1. Kliknij zielony przycisk **Code** → **Download ZIP**.
2. Rozpakuj zip do folderu Pobrane (Downloads).
3. Wszystkie ścieżki w zadaniach, np. `szablony/code-review/SKILL.md`, liczymy od rozpakowanego folderu.

## Co jest w środku

```text
├── zadania.docx                  wszystkie zadania krok po kroku, prompty do skopiowania
├── szablony/
│   ├── mcp/mcp_config.json       zadanie 4: serwery DeepWiki i Microsoft Learn
│   ├── code-review/SKILL.md      zadanie 7: skill code-review
│   ├── moje-skille/              zadanie 7: fiszki, plan-nauki, quiz-abcd, sprawozdanie-lab
│   └── agenci/                   zadanie 8: mentor.md i recenzent.md
├── pliki/demo_bad_code.py        zadania 7 i 8: kod z błędami do przeglądu
├── pakiet-final.zip              zadanie 9: Design Taste Kit do projektu food-truck-app-skills
└── do-domu/                      paczki skilli do przetestowania po warsztacie
    ├── design-taste-kit-2026-10-14.zip   skille o projektowaniu UI
    └── code-craft-kit-2026-10-14.zip     skille do pracy z kodem: plan, debugowanie, code review, subagenci
```

Kopiuj całe pliki z materiałów, nie przepisuj ich ręcznie.

## Do domu

Każda paczka w `do-domu/` ma w środku `README.md` z opisem skilli oraz instalatory `install.ps1` (Windows) i `install.sh` (macOS, Linux). Duże skille zużywają sporo limitu modelu.
